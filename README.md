# 红雨衣

> 别让穿红雨衣的人上你的车——可你已经锁死了车门。

**题材**：悬疑 · 密室 · 犯罪心理　**作者**：灯下人　**2 章 · 6,176 字**

暴雨夜，高速服务区。程远驾驶七座商务车载着六名拼车客，手机收到一条陌生短信：别让穿红雨衣的人上你的车。他锁死车门，拒绝了一个红衣人影。天亮后，警方从后备箱搜出一具穿红雨衣的女尸。程远才明白：短信不是提醒他拒绝谁上车，而是提醒他凶手就在已上车的六人里。他亲手锁死了所有人的退路，也锁死了自己的清白。
